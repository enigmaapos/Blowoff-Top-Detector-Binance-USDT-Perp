How the detector works
Gainer direction
Peak/blowoff → large selloff → trough → partial recovery.
Loser direction

Confirmation inputs
Move size, recovery fraction, volume expansion, EMA14/21/50/70/200, RSI14, and current location.
Color
Green = positive • Red = negative
Pre-breakdown alert
Searches the recent 12 completed 15m candles for a blow-off/rejection displacement attacking EMA14/21. It can also flag the first EMA50 breakdown candle so a PIEVERSE-style one-candle collapse is not missed. Uses candle body/range, ATR, volume, prior rally, EMA structure, and RSI.
Safety
One ticker request + 60 kline requests per full scan, no extra API calls for pre-breakdown detection, no overlap, limited concurrency, pacing, retry/backoff.
